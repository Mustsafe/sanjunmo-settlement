감면 한도(Cap) — 이 화면의 핵심
- [공통] Cap 200,000원은 읽기 전용 · 수정 불가. 정률 쿠폰이라도 결제 시 실제 감면액에 20만원 한계선을 강제 연산한다
- [개발] 연산 순서: ① 대상 라인 합계 × 할인율 = 산출 감면액 → ② MIN(산출 감면액, 200,000) = 실감면액 → ③ 원 단위 절사
- [공통] 숫자 예시
- 40% × 800,000원 = 320,000 → Cap 적용 200,000원 감면 · 결제 600,000원
- 40% × 450,000원 = 180,000 → Cap 미만이므로 180,000원 감면 전액 적용
- 10% 웰컴 × 189,000원 = 18,900 → 18,900원 감면
- 정액 200,000 쿠폰 × 150,000원 상품 = 150,000원까지만 감면(결제액 초과 감면 불가, 잔액 소멸)
- [UI/UX] Cap 적용으로 실감면액이 깎인 경우 주문서(USER-PAY-001)에 반드시 표기한다 — "쿠폰 최대 감면 한도(200,000원)가 적용되었습니다." 표기가 없으면 "40%인데 왜 25%만 깎였냐"는 민원이 확정적으로 발생한다
- [공통] 정산(ADMN-SETT-002)에는 실감면액 기준으로 할인 소급 비례 배분한다 — 산출 감면액이 아니다
