- 정산 계산 1~11단계는 STAGE 03 안 접힘 영역(한글 단계명 + 사용 화면만)
- 시나리오 치트시트 섹션 폐지, 각 단계 예외로 흡수
- 색: 운영=teal, 정산=pri(blue), 예외=warn. 기존 CSS 변수 재사용
