ADMN-CONF-005

관리자·외부 파트너(강사/저작권자/3PL) RBAC 권한 및 감사로그

내부 운영진 4종과 외부 파트너 3종(강사·저작권자·외부물류 3PL)의 메뉴 접근 권한 및 데이터 스코프(Data Scope)를 엄격히 분리 관리합니다.

🛡️ 운영자 작업 · 보안 감사 로그는 시스템 감사 로그에서 (ADMN-CONF-010) →
[ADMN-CONF-005] 외부 파트너 권한 3분류 분리 정책:
기존 단일 그룹이던 외부 파트너를 역할과 정산·업무 범위에 따라 [1] 파트너 강사(ROLE_PARTNER_INST), [2] 교재 저작권자/출판사(ROLE_PARTNER_COPYRIGHT), [3] 외부 물류 3PL(ROLE_PARTNER_3PL)로 명확히 분리하여, 타 파트너의 매출·정산서·회원 개인정보에 접근할 수 없도록 데이터 스코프(Data Scope: 본인 ID 격리)와 기능 스코프(Action Scope: 조회·본인승인 전용, 마감/이체/삭제 차단) 2단 통제를 강제 바인딩합니다. (※ 2계층 분할 수취인 중 원천징수 대상자는 계정 발급 없이 정산서 PDF 발송, 사업자 수취인은 정산서 확인·역발행 승인 화면만 부여)
ROLE_PARTNER_INST

[1] 파트너 강사 전용 권한

• 접근 허용: 본인 담당 강좌 학습 Q&A(ADMN-BRD-004) 답변 작성, 본인 권리자 정산내역서(ADMN-SETT-002-S2) 조회/확인
• 데이터 스코프: 바인딩된 강사코드(INST-*) 외 타 강사 매출/교재 인세/회원DB 열람 원천 차단

ROLE_PARTNER_COPYRIGHT

[2] 교재 저작권자 / 출판사 권한

• 접근 허용: 본인 저작 도서 판매량·인세(Royalty) 정산내역서 조회
• 데이터 스코프: 바인딩된 저작권 계약코드(CR-* / BOOK-*)에 한정한 열람 허용

ROLE_PARTNER_3PL

[3] 외부 물류 (3PL 배송대행사) 권한

• 접근 허용: 실물 교재 출고 대기 목록(ADMN-ORD-002) 열람 및 택배 송장번호 엑셀 일괄 업로드 전용
• 데이터 스코프: 결제금액·정산원장·수강내역 비노출 (배송 수취인 정보만 제한적 표시)
