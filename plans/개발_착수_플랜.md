# 산준모닷컴 1인 개발 가능성 검증 — 개발 착수 플랜

> 작성 2026-10-22 · 상태: **검토 중 (진행 여부 미결정)** · 작성 Claude Code · 검토 white(김영호)
>
> 이 문서는 "white + Claude Code가 로컬에서 A to Z 구현이 가능한가"를 가늠하기 위한 계획이다. 개발팀의 진행과는 별개다.
> 비밀 값(키 · 시크릿 · 비밀번호)은 이 문서에 적지 않는다. 받은 값은 `plans/개발_자료.local.md`(로컬 전용, 저장소 · 드라이브에 올라가지 않음)에 적고, 개발 환경을 만든 뒤 `.env`로 옮긴다.

---

## 1. 목적과 범위

| 항목 | 내용 |
| :--- | :--- |
| 목적 | 통합설계서 · 정산 00~04권 · 백오피스 프로토타입을 기준으로 1인 개발(A to Z)이 가능한지 실제로 만들어 보며 판단한다. |
| 범위 | 백오피스 전체(SNB 45개 메뉴) + 사용자 프론트(퍼블리싱 PHP 제공분) + 정산 엔진(1~11단계) + 외부 연동(테스트 환경) |
| 개발 장소 | 로컬 PC `D:\Work\` 아래 새 폴더. C 드라이브는 쓰지 않는다. |
| 1차 제외 | 펌뱅킹(은행 API 직접 연동) — 대량이체 엑셀로 대신 / 전자세금계산서 발행 대행 · 국세청 직접 연동 / 운영 서버 구성(코드로만 준비) / KMS 실연동 |
| 판단 시점 | 7절 진행 판단 기준 |

## 4. 정합성 검증 방식

## 6. 위험과 대응

| 위험 | 대응 |
| :--- | :--- |
| 엑셀 라이브러리의 PHP 8.5 호환 | 3-2 첫 검증 항목. 문제 시 OpenSpout로 대체 |

| 세션이 바뀌어도 일관성 유지 | 새 저장소에 작업 규칙 · 진행 상태 문서 · 규칙 대조표를 처음부터 둔다 |

| 정본 문서 해석 차이 | 개발 기준 정본 안내 + 해석 질문 목록 운영 |
