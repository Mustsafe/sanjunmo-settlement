## 2. 1차 오픈 핵심 비즈니스 정책 및 표준 용어 기준

1. **수강 플레이어 보안 제어 (동시접속 1세션 제어 우선 적용)**
   - 1차 오픈 범위에서는 동시 접속 IP/세션 제한(1계정 1세션) 및 기존 미종료 세션 강제 로그아웃(초기화)으로 구현한다. (단말기 UUID 기기 등록 UI는 2차 고도화 슬롯으로 표기)
   - 러닝타임 0초 강의(OT 등)는 기본 가중치 60초를 부여하며, 플레이어 오류 시 관리자 사유 기반 진도율 수동 보정(`ADMN-USER-004`)을 지원한다.
2. **고객센터 1:1 문의 분기 허브(`ADMN-BRD-002`) vs 학습 Q&A 분리**
   - **학습 Q&A:** 1차 오픈 시 산준모 공식 네이버 카페 질문게시판으로 아웃링크 분리한다.
   - **1:1 문의(`ADMN-BRD-002`):** 수험생 문의를 접수하여 5대 업무 화면(① 결제·환불 ➔ `ADMN-RFD-002`, ② 교재·배송 ➔ `ADMN-ORD-001/002`, ③ 수강·기기·진도율 ➔ `ADMN-USER-003/004`, ④ 합격환급·혜택 ➔ `ADMN-SETT-006`/`USER-002`, ⑤ 무료 정답지 ➔ `ADMN-BRD-010`)으로 즉시 분기·이관하는 CS 허브로 운영한다.
3. **PG 결제수단 5대 분류 (통합 상세 설계서 [표 5.1-A])**
   - 주 연동 PG사(토스페이먼츠) 기준 5대 결제수단 지원: ① 신용/체크카드, ② 간편결제 5종(토스/페이코/카카오/삼성/네이버), ③ 실시간 계좌이체, ④ 가상계좌(입금기한 24시간, 웹훅 `DONE` 시점에만 권한·출고·정산 귀속), ⑤ 휴대폰 소액결제(익월 취소 제한 시 `ADMN-USER-007` 암호화 계좌 기반 현금환불 폴백).
4. **도서정가제(최대 10% 기본할인) · 쿠폰/포인트 하드락 · 3PL 출고 잠금**
   - **실물 교재(`BOOK`, 면세):** 도서정가제 범위 내 상품 기본 할인율 최대 `10%`까지 허용(정가 취소선 + 실판매가 노출)하며, 추가 쿠폰 할인 및 포인트 사용·적립은 `0원(0%)`으로 하드락(`exclude_book = 1`)한다.
   - **정산 및 무료배송 모수:** 자사발행 도서 인세, 매출연동 개발지원금, 도서 무료배송(실결제액 합계 30,000원 이상) 판정은 모두 **할인 후 실결제액(`sale_price`)**을 기준으로 한다. 단, 위탁도서는 권리자 계약원장(`ADMN-INST-001`)에서 `실결제액` 또는 `도서 정가` 기준을 계약별로 선택한다. 패키지(`MIXED`) 쿠폰 할인액은 100% 강좌 라인에만 안분한다.
   - **3PL 출고 잠금 및 송장 업로드:** `ADMN-ORD-002`에서 3PL 출고지시 엑셀 다운로드 즉시 `배송준비중`(`ship_ordered_at`)으로 전환되어 프론트 수험생 직접 취소 및 배송지 변경이 잠금(Lock)되며, 운송장 엑셀 일괄 업로드 시 `배송중` 전환·재고 차감·알림톡 발송이 수행된다.
5. **표준 용어 및 합격환급·세무·파트너 권한 기준**
   - **포인트 2원장 명칭:** 유상 결제 연동 적립분은 **`구매적립 포인트(적립 P)`**(코드 `PAID`, 유효기간 5년), 이벤트·CS 보상 지급분은 **`무상 포인트(무상 P)`**(코드 `FREE`, 유효기간 2년)로 구분한다. 환불 시 기적립 `적립 P`를 자동 회수하며 잔액 부족 시 마이너스 부채 전환 또는 환불 현금 차감으로 처리한다.
   - **콘텐츠 표준 명칭:** 시험 대비 문제 표기는 **`빈출`**(빈출문제)로 통일하고, 교재/강좌 해답 자료는 무료 자료실 콘텐츠인 **`정답지`**(`ANSWER_SHEET`, 무료콘텐츠 `ADMN-BRD-010`)로 표기한다.
   - **합격환급반(`ADMN-SETT-006`):** 환급 인정 진도율·출석일은 패키지(`ADMN-PROD-005`)별 설정 변수를 참조하며, 4대 증빙 승인 시 교재 실판매가를 제외한 순수 강좌 결제액에서 제세공과금(22%) 공제 후 지급한다(강사 분담 차감 발생 시 개발지원금 약정 잔여한도 자동 복원).
   - **국세청·전기오류수정·파트너 RBAC:** 국세청(`ADMN-SETT-008`) 조회 장애·특수건은 증빙 첨부 후 재무 수기 예외 지정을 허용하며, 마감 후 정산 오류(`ADMN-SETT-005`)는 수취인 과세유형별 4가지 증빙 정정 방식으로 처리한다. 외부 파트너 3종(`ROLE_PARTNER_INST`, `COPYRIGHT`, `3PL`)은 메뉴 접근 제어와 데이터 스코프(본인 ID 바인딩)/기능 스코프 2단 통제를 적용한다.

## 3. 백오피스 프로토타입 폴더 구조 및 마크업 규격

### 3.1 프로토타입 2개 폴더 구분
1. **`prototype_clean/` (개발·퍼블리싱 기준 클린 UI 폴더):** 기획 설명 배너·정책 주석 박스를 제거하고 실제 운영 어드민 UI만 남긴 클린 버전.
2. **`prototype/` (기획·정책 검수용 폴더):** 화면 상단에 관련 비즈니스 정책 요약 배너 및 SSOT 검증 가이드가 함께 표시되는 기획 검수용 버전.

### 3.2 공통 레이아웃 및 컴포넌트 마크업 규격
1. **필수 공통 에셋 로드 (`<head>` 내부):** `common-v84.css` (`id="v4-common-css"`) 및 `common-snb.js` (`id="v4-common-snb"`) 로드 필수.
2. **루트 레이아웃 래퍼 (`<body>` 내부):**
   - `aside#v4-master-snb` (좌측 통합 SNB 네비게이션) + `div#v4-root-shell`
   - 상단 헤더: `header.top-bar.v4-gen3-topbar` (`.crumb-code` + `.crumb-title`)
   - 본문 컨테이너: `id="v4-page-body" class="main-container"`
3. **상단 KPI 스코어 카드 (`.kpi-grid > .kpi-card`):**
   - 내부 구조: `.k-title` (타이틀 텍스트 + `span.badge` 참조코드) + `.k-num` (Pretendard 22px Bold 좌측 정렬) + `.k-sub` (보조 설명)
