## 2. 11월 16일 오픈(1차) 스펙 조정 및 핵심 비즈니스 가드레일

문서 원문은 향후 고도화를 위해 보존하되, 11월 16일 1차 오픈용 화면 설계 및 프로토타입 구현 시 아래 실무 의사결정 사항을 우선 적용한다.

1. 수강 플레이어 보안 제어 (동시접속 IP 제한 우선 적용)
   - 문서에는 단말기 기기등록(UUID) 제어가 포함되어 있으나, 1차 오픈 개발 범위에서는 동시 접속 IP/세션 제한 및 기존 미종료 세션 강제 로그아웃(초기화)으로 구현한다. (기기 등록 UI는 2차 고도화 슬롯으로만 표기)
2. 고객센터 1:1 문의 허브(ADMN-BRD-002) vs 학습 Q&A 분리
   - 학습 Q&A: 1차 오픈 시 산준모 공식 네이버 카페 질문게시판으로 하드코딩 아웃링크 처리한다. 향후 자체 학습 Q&A 오픈 시 강사에게 직접 답변 권한(RBAC)을 부여해야 하므로 1:1 CS 문의와 메뉴를 엄격히 분리한다.
   - 1:1 문의(ADMN-BRD-002): 수험생 문의를 접수하여 문의 유형(결제·환불 ➔ ADMN-RFD-002 / 배송·교재 ➔ ADMN-ORD-001 / 수강·동시접속 / 합격환급·포인트 ➔ ADMN-SETT-006 / 학습질문 오인입 ➔ 카페 안내)별로 갈라주는 문의 분기·이관 허브로 설계한다.
   - 수강후기: 내 강의실 등에서 수험생이 작성하는 구조로 분리한다.
3. PG 결제수단 5대 분류 및 하드코딩 금지 (통합 상세 설계서 [표 5.1-A])
   - 본문에서는 연동 PG사로 추상화하고 사명은 [표 5.1-A](주 PG사: 토스페이먼츠)에서만 관리한다.
   - 지원 수단: ① 신용/체크카드, ② 간편결제 5종(토스/페이코/카카오/삼성/네이버), ③ 실시간 계좌이체, ④ 가상계좌(결제대기 24시간, ADMN-ORD-001-S1 기한 연장, 웹훅 DONE 시점에만 권한·배송·정산 귀속), ⑤ 휴대폰 소액결제(익월 환불 등 취소 제한 시 ADMN-USER-007 암호화 계좌 입력 후 현금환불 폴백).
4. 도서정가제 하드락 및 3PL 출고지시 Lock
   - 실물 교재(BOOK, 면세): 도서정가제 범위 내 상품 기본 할인 최대 10% 허용(정가 취소선 + 할인가 노출), 추가 쿠폰·포인트 사용 0원 및 포인트 적립 0% 하드락. 인세·정산·무료배송(30,000원↑) 판정은 모두 할인 후 실결제액 기준(단, 위탁도서는 계약원장에서 실결제액/정가 기준 선택). 패키지(MIXED) 할인액은 100% 강좌(LECTURE, 과세) 라인에만 배분.
   - 3PL 발주 엑셀 다운로드 즉시 ship_ordered_at 기록 및 출고지시 완료 잠금(배송지 변경 409 차단, 상위 권한 [출고지시 회수]로만 해제).

### 1.3 기존 화면설계서(`docs/screen_spec/`) 활용 및 교차검증 원칙 (무조건 신뢰 금지)
- **경로:** `docs/screen_spec/00_INDEX_화면설계서_라우팅맵.md` 및 `01`~`11` 도메인별 마크다운 파일
- **성격 및 한계:** 외주/실무 작성 과정에서 구 버전(v1~v11) 정책 잔재, 오기입, 미확정 제안 사항이 섞여 있으므로 **정본(SSOT)이 아닌 'UI 구성요소(필드·탭·모달·예외처리) 누락 방지용 체크리스트'로만 활용**한다.
- **문서 간 우선순위 서열 (충돌 시 상위 문서가 절대 우선):**
  1. **1순위 (최상위):** `README.md`의 11월 16일 1차 오픈 스펙 조정 사항 및 white의 실시간 지시
  2. **2순위 (정본 SSOT):** `docs/[산준모 정산시스템]_01~04.md` (정산·세무·계약·도서·이월) 및 `docs/산준모닷컴 구축 통합 상세 설계서.md` (회원·강좌·결제·배송·프로모션)
  3. **3순위 (참고용):** `docs/screen_spec/*.md` (기존 화면설계서 추출본)
- **AI 필수 교차검증 수칙 (화면설계서 열람 시 반드시 수행):**
  1. **정책·수치·용어 검증:** 화면설계서에 적힌 수치(예: 진도율 80% vs 90%), 필드 구조(예: 마케팅 수신 동의 SMS/이메일 분리 vs `is_marketing_agreed` 단일 필드), 용어(예: 구 용어 `Track G` vs `Pipeline 2.3`, `Kollus` vs `StarPlayer+`)가 2순위 정본 문서와 다를 경우 **무조건 정본 문서 기준으로 교정**하고, 모호하면 white에게 먼저 확인한다.
  2. **화면설계서 전용 기호 노출 금지:** 화면설계서 목업 내 원형 번호 배지(`①~⑭`, `[마커 N]`)나 디스크립션 설명 문구(`"목록에서 버튼을 누르면... 이 화면에는 폼을 두지 않는다"` 류)를 실제 프로토타입 UI에 그대로 렌더링하지 않는다.
  3. **가짜 탭 바 생성 금지:** 목록(`001`)과 상세(`002`) 등을 한 파일에 구현할 때 실제 화면에 없는 상단 탭 스위처를 노출해 UI 오인을 유발하지 않고, 좌측 SNB 메뉴(`?view=`) 및 화면 내 실제 동선 버튼(`[상세]`, `[← 목록으로]`)으로 전환한다.
